01

快速开始：画出第一张结构式

先认识四个固定区域，再用四步完成最常用的绘图流程。

1选“单键”在左侧化学键组点击单键。
2按住左键拖动松开后生成固定键长的化学键。
3添加元素从右侧选择 O、N、Cl 等，再点击键端点。
4选择并保存按 Q 返回选择，按 Ctrl+S 保存为 .nad 工程。
推荐习惯先画碳骨架，再添加元素、文字和机理箭头，最后用选择工具整体整理位置；点击左侧工具栏顶部的 ‹ / › 可以折叠或展开工具栏。
02

画布、平移、缩放与网格

画布没有边界，所有视图操作都不会改变结构的真实比例。

三种平移方法

  • 选择左侧“平移”工具后拖动画布。
  • 任何工具下按住 Space 再拖动。
  • 在画布上按住鼠标右键拖动；短按右键仍打开对象菜单。

缩放与网格

  • 滚动鼠标滚轮，或使用顶部 − / ＋。
  • 缩放范围 25%–400%，键长和结构比例保持不变。
  • 顶部“网格”按钮控制浅灰网格显示。
  • 顶部键长输入框控制新建化学键和文字的基准尺寸。
03

独立选择、框选、移动、缩放与旋转

每根键、每个原子标签和每个注释对象都可单独处理。

选择规则

  • 按 Q 或点击“选择”。点击对象只选择当前对象。
  • 从空白处拖出选择框；化学键必须完整落入框内才会入选。
  • 按住 Shift 可继续加入对象。

编辑操作

  • 拖动选中对象移动；四角或八个控制点缩放。
  • 拖动顶部圆形手柄旋转。
  • Delete 删除；Ctrl+C 复制；Ctrl+X 剪切；Ctrl+V 粘贴。
  • Ctrl+Z 撤销，Ctrl+Y 重做。
04

化学键、键级循环与碳链

所有键采用统一黑色线稿，并共享固定键长、角度辅助和价态检查。

绘制

  • 单键、双键、三键：从起点拖到终点。
  • 实心楔、空心楔、虚线楔用于立体化学；缩放时宽度随长度同步变化。
  • 碳链工具拖动即可生成连续折线，内部夹角为 120°。

自动逻辑

  • “固定标准键长”开启时，新键使用顶部设定的键长。
  • “24方向角度辅助”开启时按 15° 对齐；箭头直线和折线也参与。
  • 单键、三键工具点击已有键主体时保留键级累加。双键工具点击双键主体切换三种形态；点击单键或三键则直接改为双键。
  • 价态超限时原子出现红色虚线框；模板生成的键同样参与计算。
05

环结构与预制模板

模板由真实原子和化学键组成，放置后可以继续逐键编辑。

模板种类

  • 苯环：双键自动向环内侧绘制。
  • 环丙、环丁、环戊、环己、环庚、环辛。
  • 椅式和镜像椅式结构。
  • 乙酸乙酯键线式。

使用方法

  • 左键选择快捷模板；在模板工具上右键打开完整模板页。
  • 移动鼠标先观察半透明预览，确认尺寸和锚点后单击。
  • 放置后可单独选择任何一根键、原子或标签继续修改。
06

机理箭头、电荷、过渡态与点位

箭头由线型、路径和头部三个独立选项组合。

箭头

  • 线型：普通实线、虚线。
  • 路径：直线、三点确定曲线、连续多段直线。
  • 头部：全箭头、鱼钩头。
  • 箭头不参与旧式文本位置吸附，但文字移动到箭头中心时会出现蓝色对齐辅助线。

标记

  • 电荷：正、负、带圈正、带圈负；靠近原子会附着到原子。
  • 过渡态标记：‡。
  • 点位：圆点或叉号，可在任意位置独立放置。
  • 放置前均显示半透明预览；选择后可移动、缩放或删除。
07

括号和化学文字编辑

括号按准确边界绘制；文字是可编辑对象，而不是不可修改的图片。

括号

  • 小括号、中括号、大括号；工具上右键选择类型。
  • 手动画括号时，按下位置就是左上角，松开位置就是右下角。
  • 先框选结构再使用括号，会自动按结构轮廓留出边距。

文字

  • 先选择“文字”，再点击画布中的放置位置；画布会生成“请输入文字”文本框并自动打开编辑器。
  • 支持换行、字号、颜色、上角标、下角标，以及希腊字母、反应符号和数学标记。
  • 文字工具下点击已有文字，直接进入编辑；选择模式下右键文字也可编辑。
  • 完成文字后默认回到选择；开启“批量添加文本”后可连续放置。
08

元素标签与自动补氢

元素标签使用可编辑的化学文本排版，氢的数量按当前键级计算。

元素

  • 右侧快捷栏提供 H、C、N、O、Cl、Br；顶部小周期表按钮打开完整元素面板。
  • 选中元素后点击化学键端点，标签会统一居中到节点。
  • “自动补全隐式氢”开启时按常见价态显示 CH₃、OH 等。
  • “元素标签遮挡处理”会在文字底部自动留白，避免键穿过文字。

工程文件、图片导出与快捷键

保存 .nad 用于继续编辑；导出 JPG 或 SVG 用于论文、作业和演示。

如何切换导出类型

  • 点击顶部“导出图片”或按 Ctrl+E。
  • 在 Windows 保存窗口底部找到“保存类型”，选择“JPG 图片”或“SVG 矢量图”，再点击保存。
  • 也可打开左上角“菜单”，直接点击“直接导出 JPG”或“直接导出 SVG 矢量图”。
  • JPG兼容性好，适合聊天、作业和普通文档；SVG放大不模糊，适合论文、印刷和矢量编辑。
  • 两种格式都会按已画内容自动裁边，只在四周保留少量留白，不导出网格、选框和预览虚影。
